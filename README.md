# تحليل مخاطر الائتمان المصرفي | Bank Credit Risk Analysis

## 📌 نظرة عامة على المشروع

يهدف المشروع إلى تحليل بيانات القروض لتقييم مخاطر الائتمان، وتحديد الفئات الأكثر عرضة للتعثر في السداد، واستخراج مؤشرات تساعد على فهم المخاطر ودعم قرارات منح القروض.

## 🛠️ الأدوات المستخدمة
- **SQL Server:** فحص البيانات وتحليلها باستخدام استعلامات SQL.
- **Power BI:** إنشاء لوحة معلومات تفاعلية لعرض مؤشرات مخاطر الائتمان.

## 📊 التحليلات المنفذة
- فحص البيانات والتأكد من جاهزيتها للتحليل.
- تحليل معدلات التعثر في سداد القروض.
- مقارنة معدلات التعثر حسب درجات القروض (Loan Grades).
- استخدام SQL Server لاستخراج المؤشرات والنتائج.
- عرض النتائج ومقارنة درجات المخاطر باستخدام Power BI.

## 🔍 أهم النتائج

أظهرت نتائج التحليل اختلافًا واضحًا في معدلات التعثر حسب درجة القرض:

| درجة القرض | معدل التعثر |
|---|---:|
| A | 9.96% |
| B | 16.28% |
| C | 20.73% |
| D | 59.05% |
| E | 64.42% |
| F | 70.54% |
| G | 98.44% |

تشير النتائج إلى ارتفاع معدلات التعثر في درجات القروض D وE وF وG مقارنةً بالدرجات A وB وC، مما يوضح أهمية تقييم مخاطر الائتمان عند اتخاذ قرارات الإقراض.

## 💡 التوصيات
- إجراء تقييم أكثر دقة للقروض ذات درجات المخاطر المرتفعة.
- مراجعة البيانات المالية لمقدمي طلبات القروض قبل الموافقة.
- متابعة معدلات التعثر حسب درجة القرض بصورة دورية.
- استخدام مؤشرات الأداء في Power BI لمراقبة تغيرات مخاطر الائتمان.
- الاستفادة من نتائج التحليل لدعم قرارات منح القروض وإدارة المخاطر.

## 📈 مخرجات المشروع

تم استخدام SQL Server لتحليل البيانات واستخراج المؤشرات الرئيسية، ثم استخدام Power BI لعرض النتائج في لوحة معلومات تساعد على مقارنة معدلات التعثر وفهم توزيع مخاطر الائتمان.

## ✅ الخلاصة

ساهم المشروع في تطبيق مهارات تحليل البيانات باستخدام SQL Server وPower BI، بدءًا من فحص البيانات وتحليلها، وصولًا إلى عرض النتائج واستخراج توصيات مبنية على البيانات لدعم فهم مخاطر القروض والتعثر في السداد.
